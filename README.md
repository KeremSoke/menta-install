# Menta Install

Software Manager for Debian and Debian Menta. It lets you browse, install and
remove applications, from the Debian repositories and from Flatpak remotes.

Forked from Linux Mint's [mintinstall](https://github.com/linuxmint/mintinstall).

## Features

- Landing page with a slideshow of featured applications, picks and top rated apps.
- Categories (Internet, Graphics, Games...) filled from curated lists in
  `usr/share/menta-install/categories` and from the Debian package sections.
- Search in package names, summaries and descriptions, optionally limited to the
  current category.
- Details page with description, screenshots, version, size, homepage, ratings
  and reviews.
- When an app exists both as a Debian package and as a Flatpak, you can pick which
  one to install (`apt_flatpak_match_data.info` links them).
- Flatpaks:
  - every Flatpak shows whether its developer was verified by Flathub
    (blue **Verified** badge, red **Unverified Flatpak** badge);
  - unverified Flatpaks are hidden unless enabled in the preferences;
  - add-ons, `.flatpakref` and `.flatpakrepo` files, and `flatpak+https://` links.
- Installed applications view, and a list of the operations in progress.
- Traditional menu bar: File, Edit, View and Help.
- **Package installer** for local `.deb` files, like GDebi: double-click a `.deb`
  (or use **File > Open Package File**) to see its description, details, included
  files and the dependencies it needs, then install, reinstall, upgrade or remove it.
  Dependencies are installed from the repositories by PackageKit.
- **Find an application for a file type**: menta-install provides the PackageKit
  session D-Bus interface (`org.freedesktop.PackageKit.Modify`/`Modify2`). When a
  file has no application, the file manager (Caja: "Do you want to search for an
  application to open this file?") opens menta-install with the Debian packages
  and Flatpaks able to open it, found in the AppStream catalogs.

### Where the data comes from

| Data                          | Source                                                        |
|-------------------------------|---------------------------------------------------------------|
| Debian packages               | APT (`python3-apt`), installed and removed with PackageKit     |
| Icons of Debian packages      | Icon theme, then the DEP-11 AppStream icons downloaded by APT (`appstream` package), then `/usr/share/pixmaps` |
| Screenshots of Debian packages| [screenshots.debian.net](https://screenshots.debian.net)       |
| Flatpaks                      | libflatpak and the AppStream data of each remote               |
| Ratings and reviews           | [Open Desktop Ratings Service](https://odrs.gnome.org), shared with GNOME Software and KDE Discover |

Ratings are cached in `~/.cache/menta-install/ratings.json` and refreshed once a day.
Reviews can be written from the **Reviews** tab of an application.

The package cache is stored in `~/.cache/menta-install/pkginfo.json`, or in
`/var/cache/menta-install/pkginfo.json` when generated by `menta-install-update-pkgcache`.

## Commands

| Command                          | Description                                                |
|----------------------------------|------------------------------------------------------------|
| `menta-install`                  | Opens the Software Manager                                 |
| `menta-install install <file>`   | Opens a `.deb`, `.flatpakref` or `.flatpakrepo` file       |
| `menta-install search-mime <type>...` | Lists the applications which can open these MIME types |
| `menta-install show <package>`   | Shows a package (Debian package or Flatpak ID)             |
| `menta-install-fp-handler <url>` | Handles Flatpak files and `flatpak+https://` links         |
| `menta-install-update-pkgcache`  | Regenerates the package cache                              |

Set `DEBUG=1` to print debug information and timings.

## Build

Get source code
```
git clone https://github.com/KeremSoke/menta-install
cd menta-install
```
Build
```
dpkg-buildpackage --no-sign
```
Install
```
cd ..
sudo apt install ./menta-install_*.deb
```

To try changes without building a package, run `./test` (it copies the files to `/usr`).

## Translations

Run `./makepot` to update `menta-install.pot`. Translations use the `menta-install`
gettext domain and are installed in `/usr/share/locale`.
